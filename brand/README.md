# TLC_TRNG brand masters

Copied from Dropbox `2_TLC_TRNG/4_Branding/ds-bundle/guidelines/logos/` (2026 masters). The source of truth for colour, type and logo rules is `guidelines/brand-design-system.md` in the same Dropbox folder; InfoCapture uses the primary TLC_TRNG palette, not the PREPARE or TrainMe sub-brands.

| File | Used for |
| --- | --- |
| `tlc-trng-horizontal-navy.png` | "InfoCapture by TLC_TRNG" sign-off in Settings, light mode |
| `tlc-trng-horizontal-gray-white.png` | The same sign-off in dark mode |

`npm run assets` builds the wordmark images in `app/icons/` from these, and draws the app icon: InfoCapture's own glyph (scan corners around a contact card) in TLC_TRNG neon cyan, glowing, on navy, the same colours as the Snap card button. Do not recolour or edit the masters; replace them from Dropbox when the brand updates.

Fonts in `app/fonts/` are Montserrat (headings, buttons) and Open Sans (text), latin and latin-ext subsets from Google Fonts, both under the SIL Open Font License 1.1.
